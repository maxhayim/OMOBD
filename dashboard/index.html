Table view

Sensors and connection status

Every input configured on the unit. "Calculated" values are derived from measured ones and are labelled everywhere they appear.

Engine profile

Wiring a profile's sensors is done with the matching preOBD config file (see the engine's folder in engine-profiles/) imported over USB with JSON IMPORT. Selecting a profile here sets the dashboard layout and the profile name stored on the unit.

Display units

Sensor values are shown in the units configured on the unit (preOBD SET <pin> UNITS).

Unit status

Logging

Starts or stops preOBD's SD-card log until the next restart (same as OUTPUT SD_Log ENABLE without SAVE). Needs an SD card module.

Backups

Wi-Fi passwords are never included in downloads.

Device settings

Changes need the unit's Wi-Fi password (it's printed on the USB console at start-up). Pins are preOBD input pin numbers; null = not fitted. Leave oilCurve.points empty until you have validated figures for your engine.
